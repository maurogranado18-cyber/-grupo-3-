Acerca de nosotros

Somos un equipo de estudiantes de RollingCode que diseñó y maquetó este sitio de streaming como proyecto grupal, trabajando con metodología Scrum y dividiendo el trabajo en sprints.

Para construirlo usamos HTML, CSS y Bootstrap, organizamos las tareas en Trello y versionamos el código con Git y GitHub.

“Nuestro propósito es entretener al mundo”
