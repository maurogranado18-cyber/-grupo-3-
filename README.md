# NÉBULA 🎬✨

Plataforma web de streaming de películas y series desarrollada como proyecto colaborativo para el curso de desarrollo web de RollingCode School.

## 🚀 Descripción del Proyecto

**NÉBULA** es una interfaz moderna de streaming diseñada para ofrecer una experiencia de usuario fluida, permitiendo navegar por un catálogo dinámico de contenidos, acceder mediante un sistema de inicio de sesión simulado y gestionar interacciones con la plataforma.

## 🛠️ Tecnologías Utilizadas

El proyecto fue construido utilizando tecnologías web estándar y metodologías modernas de desarrollo:

- **HTML5:** Estructura semántica de las páginas.
- **CSS3 & Bootstrap:** Estilos personalizados y diseño responsivo adaptado a dispositivos móviles y de escritorio.
- **JavaScript (ES6+):** Lógica de la aplicación, dinamismo e interactividad.
- **Git & GitHub:** Control de versiones y trabajo en equipo mediante flujo de ramas (`develop` / `main`).
